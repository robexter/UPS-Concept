UPS Concept PWA
================

Arquivos:
- index.html
- manifest.json
- sw.js
- icon-192.png
- icon-512.png

Publicação no GitHub Pages:
1. Crie ou abra um repositório.
2. Envie TODOS os arquivos para a raiz do repositório.
3. Vá em Settings > Pages.
4. Em Source, selecione Deploy from a branch.
5. Escolha branch main e pasta /root.
6. Aguarde a publicação.
7. Abra o link pelo Chrome no Android.
8. O botão "Instalar App" aparecerá quando o navegador considerar o PWA instalável.

Se uma versão antiga aparecer:
- Feche a página.
- Limpe o cache/dados do site no navegador ou remova o app instalado.
- Reabra o link publicado.
